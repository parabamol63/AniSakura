# Publish the AniSakura CloudStream repository

The extension package and manifests are published in the public `parabamol63/AniSakura` CloudStream repository under `AniSakura/`.

Add this raw repository manifest URL in CloudStream Desktop under **Settings → Extensions → Add Repository**:

`https://raw.githubusercontent.com/parabamol63/AniSakura/master/AniSakura/repo.json`

Then install AniSakura from the repository.
